# TMDB Movie Data Analysis 🎬

An Exploratory Data Analysis (EDA) of 10,000+ top-rated titles from The Movie Database (TMDB) to identify content trends and audience engagement metrics.

## Key Insights
* **Exploratory Data Analysis**: Conducted comprehensive EDA on 10,000 TMDB titles using Pandas and Seaborn to identify content trends and viewer rating distributions.
* **Market Insights**: Discovered that English films comprise 80% of top-rated media, leveraging Python to drive data-informed marketing and content strategies.
* **Engagement Trends**: Identified that top-tier popular movies receive over 100,000 votes, signaling critical audience engagement benchmarks.

## Technologies Used
* **Language**: Python
* **Data Manipulation**: Pandas
* **Visualization**: Matplotlib, Seaborn
* **Environment**: Jupyter Notebook

## Project Structure
* `TMDB_Movies_Analysis.ipynb`: Main analysis notebook containing data cleaning, visualization, and statistical modeling.
* `tmdb_5000_movies.csv`: Dataset used for the analysis (if applicable).

## Analysis Workflow
1. **Data Cleaning**: Handled missing values and standardized metadata for 10,000 entries.
2. **Distribution Analysis**: Visualized frequency of ratings and vote counts to identify market leaders.
3. **Correlation Studies**: Analyzed the relationship between movie popularity and user ratings to determine content success factors.
